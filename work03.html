ABOUT PROJECT

UnityとC#を使用して制作した アクションゲームです。

プレイヤー操作、ジャンプ、アニメーション、 敵との当たり判定、UI、シーン遷移などを実装しています。

RESPONSIBILITIES

PLAYER CONTROL

プレイヤーの移動やジャンプなどの キャラクター操作を実装。

ANIMATION

Animatorを使用して、 移動・ジャンプなどのアニメーション制御を実装。

COLLISION

プレイヤー、敵、障害物などの 当たり判定を実装。

UI

HP、タイマー、タイトルなどの UI表示を実装。

TECHNICAL POINTS

01 / PLAYER MOVEMENT

Unityの入力システムを使用し、 プレイヤーの移動やジャンプ処理を実装しています。

02 / ANIMATION CONTROL

Animator Controllerを使用して、 キャラクターの状態に応じた アニメーション切り替えを行っています。

03 / GAME MANAGEMENT

GameManagerを使用して、 ゲームの進行、タイマー、UIなどを管理しています。
